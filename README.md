# Selah — Salon Booking App

## Tech Stack
React + Vite + PWA | Hosted on Vercel | Packaged via PWA Builder

---

## Local Development
```
npm install
npm run dev
```
Open http://localhost:5173

## Build for Production
```
npm run build
npm run preview
```
